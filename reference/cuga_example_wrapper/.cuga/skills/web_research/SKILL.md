# Web Research Skill

When researching:

1. State the research question precisely.
2. Prefer primary or authoritative sources.
3. Separate facts from inference.
4. Cross-check important claims.
5. Record the source or evidence supporting each important conclusion.
6. If a custom web-search/fetch tool is available, use it rather than inventing access to the web.
7. Do not claim to have browsed the web unless an actual web/browser/search tool was invoked.
