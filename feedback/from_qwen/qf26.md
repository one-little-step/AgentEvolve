## Bug 1: The Rich Trace Never Reaches the Core Analyzer

### What should happen:
```
CUGA Agent runs → Produces rich CausalTrace (56 events with parent/child edges)
                        ↓
              CugaAdapter.capture_trace()
                        ↓
              Core Analyzer reads events, finds actor_ids
                        ↓
              Builds Causal Blame Graph (H2)
```

### What actually happens:
```
CUGA Agent runs → Produces rich CausalTrace (56 events)
                        ↓
              CugaAdapter.capture_trace() ← SEVERED HERE
                        ↓
              Returns a THIN trace with:
                - actor_id = None (hardcoded)
                - parent_event_id = None (hardcoded)
                - Only 2 events (run_started, run_completed)
                        ↓
              Core Analyzer finds ZERO actors
                        ↓
              Blame Graph is EMPTY → "insufficient_evidence"
                        ↓
              H2 (causal blame) NEVER WORKS
```

The adapter has the rich trace file path (`causal_trace_path`) in its result, but it **throws it away**. It reads from the thin `result["trace"]["events"]` list instead of the rich persisted trace. So the beautiful 56-event DAG you verified in `causal-trace.json` never reaches the analyzer.

## Bug 2: Edits Never Reach the CUGA Agent (The Bigger Problem)

### What should happen:
```
Editor proposes edit → Adapter applies edit to workspace
                        ↓
              run_full_rollout() reads the EDITED workspace
                        ↓
              CUGA Agent loads the EDITED skills/policies/memory
                        ↓
              Agent behaves DIFFERENTLY because of the edit
                        ↓
              Score changes → Evolution measures the effect
```

### What actually happens:
```
Editor proposes edit → Adapter applies edit to in-memory dict
                        ↓
              run_full_rollout() passes ONLY {"input": task.input_text}
                        ↓
              CUGA Agent loads the ORIGINAL (unedited) harness
                        ↓
              Agent behaves IDENTICALLY regardless of edits
                        ↓
              Score is pure MODEL NOISE → Evolution measures nothing
```

Here's the chain of failures:

1. **`apply_structured_edits()`** modifies `self._workspaces[version]` — an in-memory dictionary.
2. **`run_full_rollout()`** calls `self.wrapper.run_task(task.task_id, {"input": task.input_text})` — it only passes the input text, **not the edited artifacts**.
3. **`materialize_harness()`** inside the wrapper looks for `skills`, `policies`, `memory` keys in the harness config — but they're never provided, so it returns `None`.
4. **`get_artifacts()`** returns `self._artifacts` which is empty by default — so `artifact_inventory()` is empty and there's nothing for the editor to select.

**The net result:** Every "accepted edit" in the evolution loop has zero effect on the agent's actual behavior. The optimizer would measure random model noise and could report a "winning" candidate based purely on luck. This is a **fabricated-evidence risk** — the most dangerous failure mode because it looks like the system is working when it isn't.

## Why "Quietly Inert" Is Dangerous

Your Phase 6 guard (`insufficient_evidence` when no blame nodes exist) is working correctly. But here's the problem:

- **Wrong** = The system produces incorrect results that look plausible. You'd catch this eventually.
- **Inert** = The system produces no results at all, but doesn't crash or error. It just silently does nothing useful.

With the current adapter:
- Every rollout produces `insufficient_evidence` (because actor_ids are None)
- Every edit has no effect (because edits don't reach the agent)
- The loop runs, tests pass, but **no actual evolution happens**

This is worse than a crash because you might not notice it until you try to run a real experiment and get meaningless results.

## The Proposed Fix (In Priority Order)

| Priority | Fix | Why It Matters |
|---|---|---|
| **1 (Critical)** | Wire `run_full_rollout()` to pass the candidate's edited artifacts as `skills`/`policies`/`memory` to the CUGA wrapper | Without this, edits have zero effect. Everything else measures nothing. |
| **2 (Critical)** | Map `actor_id` and `parent_event_id` through `capture_trace()`, sourcing from the rich trace | Without this, H2 causal blame never works. |
| **3 (Blocking #2)** | Decide the raw-payload gate (how to prevent `expected_answer` from leaking into analyzer prompts via the rich trace) | Must be resolved before the rich trace reaches the analyzer. |
| **4 (Important)** | Seed `artifact_inventory()` from the real harness configuration | Without this, the editor has nothing to select or edit. |
